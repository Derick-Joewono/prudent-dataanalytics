# prudent-dataanalytics
This was made for practice purpose for data analytics intern role in Prudential Syariah 
I used 2 datasets which can be access in folder datasets. 

The source link of dataset used for this project can be access through these links : 

1. https://www.kaggle.com/datasets/janiobachmann/bank-marketing-dataset (role play simulation fullfilling request from business and campaign division)
2. https://www.kaggle.com/c/prudential-life-insurance-assessment/data (role play simulation to enhance efficiency insurance risk analysis that could take up to 30 days manually but minutes with machine learning)

To run this project, makesure to clone this project and type "pip install -r requirements.txt" on your terminal to automatically download all the dependencies needed. Also makesure to use your venv. 

Then you can run every block code in prudential_practice.ipynb. All the answers and solutions is saved inside folder 'solutions'. 

That's it, thanks for reading ^_^.
